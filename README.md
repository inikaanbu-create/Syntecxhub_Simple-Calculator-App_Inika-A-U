# Simple Calculator App

A simple Android calculator application developed using **Kotlin and XML layouts** as part of the Syntecxhub Android Development Internship.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal calculations
* Clear button
* Delete button
* Divide-by-zero handling
* Invalid-input validation
* Responsive Android layout

## Technologies Used

* Kotlin
* XML
* Android Studio
* Android SDK
* Material Components

## Project Structure

```text
SimpleCalculatorApp/
├── app/
│   └── src/
│       └── main/
│           ├── java/
│           ├── res/
│           └── AndroidManifest.xml
├── build.gradle.kts
├── settings.gradle.kts
└── gradle.properties
```

## How to Run

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to synchronize.
4. Connect an Android device or start an emulator.
5. Click **Run**.

## Testing

The calculator was tested for:

* Addition
* Subtraction
* Multiplication
* Division
* Decimal values
* Clear/delete operations
* Division by zero
* Invalid expressions
